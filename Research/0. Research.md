# Malicious-URL-Creation and Detection
This software is for generating a malicious URL for demo purpose and contains a Malicious URL Detection system.

## Software is divided into two parts:
1. Malicious URL Generation
    - A malicious URL for cam images stealing
    - Components - Ngrok
    
2. Malicious URL Detection
    - Data Receiver: It receives data from the user i.e. URL and IP.
    - Model1 (URL Classifier): for classifying URL as Safe or Malicious.
    - Model2 (URL Rating): for calculating the level of maliciousness of URL.
    - Sandbox - for executing URL in virtual environment.
    
    **Algorithm used:**
    - Based on FalconDB
    - Every node will contain following components:
        - Data Structure for storing Maliciousness level and Reputation score
        - Model1 and model2 for classifying the url and quatifying the malicious level.
        - Blacklisting algorithm
    - Based on rewards and penality and rewards
    






**DataSet used: https://www.kaggle.com/datasets/sid321axn/malicious-urls-dataset**
